# OctoAcme Project Management Docs

This folder contains OctoAcme's project management process documentation and serves as the entry point for understanding how our teams plan, deliver, and improve work.

## Project management process summary

OctoAcme uses a customer-first, iterative delivery model with clear ownership and measurable outcomes. Each project is expected to have a named Project Manager and Product Lead, a prioritized backlog with acceptance criteria, and a lightweight plan that defines milestones, dependencies, and resource needs. Teams work in small, testable increments, with regular alignment meetings, demos, and retrospectives to learn and adjust.

Core practices include:
- Initiating projects with a clear problem statement, stakeholders, and success metrics
- Planning work into prioritized backlog items with estimates and explicit acceptance criteria
- Executing delivery with daily rhythm, progress tracking, and blocker escalation
- Managing risks, dependencies, and stakeholder communication throughout the lifecycle
- Releasing features with quality checks, smoke tests, and rollback planning
- Capturing learnings in retrospectives and turning them into improvement actions
